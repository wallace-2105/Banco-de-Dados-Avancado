Fundamentos e Arquitetura Oracle PL/SQL

Revise os conceitos-chave, sintaxes de comandos, procedures, triggers e controle de transação antes de testar suas habilidades nos desafios interativos.

➤
PL/SQL (Procedural Language/SQL): É uma extensão procedural do SQL no Oracle. Permite o uso de recursos como loops, condicionais (ifs), declaração de variáveis e tratamento robusto de exceções dentro do próprio motor de banco de dados.
➤
Comandos Importantes de SELECT:
  • DISTINCT: Remove duplicatas do conjunto resultante de registros.
  • Operadores de Filtro: LIKE (com caractere coringa % para qualquer sequência de caracteres), IN (pertencimento a lista), BETWEEN (intervalos inclusivos) e IS NULL (verificação de valores nulos).
  • A cláusula ORDER BY ordena os dados: por padrão em ordem ascendente (ASC) ou inversa/decrescente (DESC).
Exemplo de Consulta SQL com Filtros e Ordenação 
SELECT DISTINCT first_name, salary
FROM employees
WHERE first_name LIKE 'M%'
  AND salary NOT BETWEEN 1000 AND 2000
ORDER BY salary DESC, first_name ASC;

Procedure

Execução de Tarefas

Bloco PL/SQL nomeado que executa tarefas ou operações no banco. Não precisa retornar valores diretamente através de comando return (embora possa utilizar parâmetros do tipo OUT).

Sintaxe Padrão:
CREATE OR REPLACE PROCEDURE nome (param IN tipo) IS
BEGIN
  -- Comandos DML ou lógica procedural
  UPDATE funcionarios SET status = 'demitido' WHERE cd_func = param;
  COMMIT;
END;

Function

Cálculo & Retorno

Similar à procedure, mas obrigatoriamente retorna um valor com a cláusula RETURN. Muito usada dentro de instruções SQL para transformar dados em tempo de execução.

Sintaxe Padrão:
CREATE OR REPLACE FUNCTION nome (param IN tipo) 
  RETURN tipo IS
BEGIN
  -- Cálculo ou transformação
  RETURN valor;
END;

Estrutura Condicional (IF)

Avalia condições encadeadas com a palavra-chave ELSIF (atenção à grafia sem "e" intermediário):

IF cond THEN
  -- código 1
ELSIF cond2 THEN
  -- código 2
ELSE
  -- padrão
END IF;

Estruturas de Repetição (Loops)

  • LOOP Básico: requer término manual com EXIT WHEN cond;
  • WHILE LOOP: repete enquanto a condição for verdadeira.
  • FOR LOOP: itera por um intervalo fechado com sintaxe: FOR i IN 1..5 LOOP ... END LOOP;
FOR v_counter IN 1..5 LOOP
  DBMS_OUTPUT.PUT_LINE('Contador: ' || v_counter);
END LOOP;

Tratamento de Exceções (Bloco EXCEPTION)

Tratamento de erros de execução capturados no bloco final do código PL/SQL:

ZERO_DIVIDE (Divisão por zero) NO_DATA_FOUND (Nenhum registro encontrado em SELECT INTO) TOO_MANY_ROWS (Múltiplas linhas em SELECT INTO escalar) WHEN OTHERS (Captura genérica de erros não mapeados)
➤
Disparo Automático: Gatilhos disparados automaticamente por eventos DML (INSERT, UPDATE, DELETE) ou eventos DDL / de sistema.
➤
Momento da Execução: Podem ocorrer BEFORE (antes da validação/gravação dos dados, ideal para auditoria prévia ou impedir reduções salariais) ou AFTER (depois do evento).
➤
Pseudo-registros :NEW e :OLD:
  • :NEW: Contém os novos valores que estão sendo inseridos ou atualizados.
  • :OLD: Contém os valores antigos antes da alteração ou os registros prestes a serem apagados no DELETE.
➤
Cláusula FOR EACH ROW: Define que o gatilho será acionado para cada linha afetada pelo comando DML (nível de linha), e não apenas uma única vez para toda a instrução SQL (nível de instrução).
Exemplo de Trigger com Regra de Negócio e :OLD/:NEW 
CREATE OR REPLACE TRIGGER trg_valida_salario
BEFORE UPDATE ON employees
FOR EACH ROW
BEGIN
  IF :NEW.salary < :OLD.salary THEN
    RAISE_APPLICATION_ERROR(-20001, 'Redução salarial não permitida!');
  END IF;
END;

1. Sequences no Oracle

Objeto gerador de números sequenciais crescentes ou decrescentes, comumente utilizado para preenchimento de chaves primárias (PK).

seq_nome.NEXTVAL Gera e retorna o próximo número sequencial da sequência.
seq_nome.CURRVAL Retorna o valor atual da sequência na sessão atual.

2. Tipos de Junções (Joins)

Tipo de Join Comportamento no Conjunto de Dados Exemplo Conceitual
Inner Join Retorna apenas a interseção (coincidência exata) entre as duas tabelas. FROM Emp E INNER JOIN Dept D ON E.dept_id = D.id
Left Join Retorna todas as linhas da tabela da esquerda (primeira declarada), mesmo sem correspondência na direita. Preserva funcionários sem departamento atribuído.
Right Join Retorna todas as linhas da tabela da direita (segunda declarada), mesmo sem correspondência na esquerda. Preserva departamentos sem funcionários alocados.
Full Join Junta o Inner Join com Left e Right Join (todas as linhas de ambos os lados). Linhas sem par recebem NULL nas colunas opostas.
Cross Join Produto cartesiano irrestrito (multiplica linhas da tabela A pelas da B: se A=3 e B=3, resulta em 9 linhas). FROM TabelaA CROSS JOIN TabelaB
Natural Join Une tabelas automaticamente por colunas de mesmo nome. Gera erro de execução se as colunas homônimas possuírem tipos de dados diferentes (ex: NUMBER vs VARCHAR2). FROM Emp NATURAL JOIN Dept
